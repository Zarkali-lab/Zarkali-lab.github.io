# Getting started

## Accounts

Create or confirm access to:

- institutional email and calendar
- lab GitHub organisation
- shared storage and approved research drives
- HPC / cluster account where required
- study-specific REDCap, imaging or clinical systems

Never place identifiable participant data in GitHub repositories, personal cloud storage or unapproved devices.

## Local development

Recommended baseline:

```text
Git
Python 3.11+
VS Code / Neovim / preferred editor
SSH client
Docker where useful
```

Use project-specific environments rather than one global Python environment.

## Repositories

One repository should answer one clear question or support one reusable tool. Put setup steps in `README.md`; keep environment files under version control; use issues for work that needs discussion or traceability.
