# Welcome to the lab

This wiki is the shared operating manual for the lab. It should answer routine questions quickly and make our working practices visible to everyone.

> **Principle:** document decisions once, then improve the documentation when reality changes.

## What belongs here

- onboarding and access instructions
- lab meetings and recurring routines
- data, code and reproducibility standards
- analysis conventions and shared pipelines
- writing, review and publication practices
- practical tips that otherwise disappear into chat or email

## How to use the wiki

Use search on the wiki landing page, or browse by category. Every page is plain Markdown in `content/wiki/`, so edits can be made directly on GitHub and reviewed through pull requests.

## First week checklist

1. Read **Getting started**.
2. Set up GitHub and shared compute access.
3. Read **Data & code** before copying any research data.
4. Add yourself to People page.
5. Bring unclear or outdated guidance to next lab meeting.
